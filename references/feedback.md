# 读懂设计反馈：口语 → 动作

用户给的是感受，不是规格。下表把常见说法翻成具体动作。例子都来自审稿页主页改版（2026-10-29 / 30）。

## 对照表

| 用户说 | 真正的问题 | 先这样做 | 例子 |
|---|---|---|---|
| 「不好看」「还要改」「还要调」（没给方向） | 方向不对，不是参数不对 | 不微调；换一个方向明确的版本，或出 2–3 个候选拼成对比图让用户选 | 第三栏纸纹：丝帛 / 笔记本 / 方格纸三选一，用户一次选定 |
| 「甚至不如上一个版本」 | 新方向整体被否 | 先回退上一版，再问或再提别的方向 | 上两栏 + 下列表的布局被否，退回四栏 |
| 「太抢眼」「抢戏」「太繁复」 | 装饰压过内容 | 缩小 → 降对比 → 减数量 → 挪到边缘 → 删 | 底排剪刀从平铺到只露 11px 把手；栏角小画全部删掉 |
| 「不是主角了」 | 内容层级被装饰稀释 | 删装饰，内容本身不加花样 | 删栏角小画，数字挪位，纸纹收淡 40% |
| 「太规整」「太对称」「像印刷体」 | 缺手作的不规则 | 每个实例做出差异：形状、角度、高光、方向 | 巴洛克珍珠；每栏纸纹不同；薰衣草方向各异；手写数字每栏歪度不同 |
| 「没质感」「塑料感」「假」「反光假假的」 | SVG / 渐变画不出材质 | 换照片级素材（`materials.md`） | 剪刀：SVG 平涂 → SVG 金属渐变（塑料感）→ 照片 |
| 「不像真的」 | 造型凭空想象 | 找实物参考照片，按实物生成 | 钟、火漆、麻绳都按参考图生成 |
| 「不搭」「不适配」「和整体不和谐」 | 颜色族 / 材质族 / 形状语言和邻居冲突 | 对齐到邻居：同色族、同材质、同形状 | 周历纸条和顶栏胶囊不搭 → 改成同款胶囊；缎布和粉纽扣不搭 → 同为粉色族 |
| 「太空」 | 固定尺寸里内容没排好 | 内容居中、相关的贴近；不要用装饰填空 | 卡片标签从贴底改成紧跟标题 |
| 「太挤」「没有呼吸感」 | 分割线、边框太多 | 去分割线，靠留白分区 | 顶栏下的分割线删掉 |
| 「显示不全」 | 文字比容器长 | 先精简文字，再考虑折行 / 淡出 | 「已优化 · 还剩 90 天」→「改过 · 剩 90 天」 |
| 「太小 / 看不清」又「太大 / 抢戏」 | 尺寸在两头摇 | 定一个中间值，同时用对比度而不是尺寸取得可读 | 剪刀 17px 太小、36px 太抢，最后 26px 照片 + 只在交互时出现 |
| 「是刻意的还是 bug？」 | 用户看到了异常 | 先诚实回答，再复现、修、说明验证到哪一步 | 弹窗剪刀隔几秒抖一下 |
| 「怎么没了」 | 改别的东西时碰坏了 | 查最近改动对它的影响（CSS 覆盖最常见） | 火漆转圈丢失：新写的 `transition: opacity` 覆盖了 transform 过渡 |

## 「不是……」句式：你越界了

用户说「我的意思不是让你……」「不是替换」「注意只是改颜色」「下面的要保留」，说明上一次改动超出了用户指的范围。处理：

1. 把越界改掉的部分恢复。
2. 只改用户点名的那个属性。
3. 风格文档里把边界写明，下次不再犯。

实例：

- 「把这一栏的底色改到第一栏（只是改颜色，不是替换，也不是让你把小雏菊去掉）」
- 「不是让你改成大海的蓝色，现在的颜色很好」
- 「把卡片上的剪刀去掉（不是把页面下面的也去掉）」

## 参考图：照抄还是只取感觉

- 用户说「仅参考不要照抄」「这种感觉」：提炼感觉（材质、氛围、配色关系），形状按我们页面的功能来设计。
- 用户说「要我给你的参考图，不要自己想一个」：严格按参考图的造型生成。
- 拿不准时先按「取感觉」做，并说明可以改成照参考图做。

## 位置和方位要确认

「顶部」「下面」「左上」这类词容易误读（「我说的顶部是邮戳那个顶部，不是下面的顶部」）。动手前用页面上的元素来复述位置：「放在火漆所在的窗口上沿，按钮下面一层」。

## 用户给出的设计原则，记成规则

用户在反馈里顺口说出的原则，比单次修改更重要，写进风格文档的「不要」或规则节：

- 卡片 / 内容是主角。
- 好玩的交互不加提示，留给用户自己发现。
- 静止时不能卡。
- 有质感、简约、和整体统一。
