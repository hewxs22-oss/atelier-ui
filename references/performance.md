# 性能与踩过的坑

## 规则

1. **静止时零重画**。页面放着不动 5 秒，主线程占用应接近 0。用 CDP `Performance.getMetrics` 量 `TaskDuration`（见 `verify.md`）。
2. **动效只动 `transform` / `opacity`**，跑在合成层上，不触发重绘。
3. **动效有起止**：悬停或点击触发、跑一次就停（`animation-iteration-count: 1`），不做无限循环的闪烁、呼吸。唯一常驻的动画要轻（例如钟摆，只转一个小元素）。
4. **模糊、噪声只算一次**：湿痕、阴影这类带模糊滤镜的东西，先画到离屏小图（sprite），再贴；不要每帧 `filter: blur`。
5. **不要在会动或很大的元素的容器上放 `filter`**：容器带 filter 时，子元素不能独立合成，别的动画触发重栅格化时会整块重画，看起来「隔几秒抖一下」。filter 放到叶子元素上。
6. **canvas 动画按需跑**：有拖拽或还在晃才 `requestAnimationFrame`，静下来就停；外部事件（图片加载、窗口变化）来了再 kick 一次。
7. **第一帧就对**：主题 / 模式 class 在 `<body>` 后紧跟的内联脚本里从 localStorage 读出来套上，避免刷新时先闪默认样式；顶栏这类大面积不要做颜色过渡。

## 坑（症状 → 原因 → 修法）

| 症状 | 原因 | 修法 |
|---|---|---|
| 电脑很卡，风扇转 | 雨天湿痕每帧 canvas 模糊重画，静置主线程 105% | 湿痕预渲染成 sprite；没有变化就停 rAF；去掉无限闪烁 |
| 刷新时先闪一下黑色顶栏 | 样式模式在 JS 加载后才套上；顶栏有颜色过渡 | 第一帧内联脚本套 class；去掉过渡 |
| 弹窗里的物件隔几秒抖一下 | 容器带 `drop-shadow`，子图不能独立合成；钟摆动画触发重栅格化 | filter 移到每张图自己身上；容器不做 scale 过渡 |
| 动画里的物件前几秒是糊的 | 飞行时用的是 200px 内嵌小图放大，落地后才换大图 | 一开始就用大图 |
| 换了素材，用户还看到旧的 | 浏览器缓存 | 素材地址带 `?v=N` |
| 点击转圈的动效没了 | 新加的 `transition: opacity` 覆盖了原来的 `transition: transform` | 同一元素的 transition 写成一条：`transform .9s ..., opacity .6s` |
| 双击彩蛋时把旁边的大数字选中 | 浏览器默认双击选词 | 触发元素 `mousedown` 里 `preventDefault()`；标题区 `user-select: none` |
| 悬停虚线框不见了 | 卡片设了 `overflow: hidden`，虚线框在卡片外 4px | 卡片不裁 overflow，只给需要截断的文字设 |
| 首屏某物件被画布上的绳子盖住 | 画布先画、图片后到，擦除时图片还没尺寸 | 图片 `onload` 后重画一次画布 |
| 整栏变成深灰 | SVG data URI 里 `#` 先手写成 `%23`、又被编码一次成 `%2523` | 只编码一次；编码后检查不含 `%2523` |
| 固定高度卡片里一大块空白 | `justify-content: space-between` 把标签推到底 | 内容居中，相关元素贴近 |
| 新加的装饰把纸往上推了 | 装饰进了文档流 | 绝对定位放进已有留白，不占布局 |
| 薄纱挡住导航按钮 | 层级放错 | 放在导航栏这个层叠上下文里 `z-index: -1`：在背景之上、按钮之下 |
