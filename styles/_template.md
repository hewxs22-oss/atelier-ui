# 风格包模板

新风格复制这份到 `styles/<风格名>.md`，填完再开工。通用层（`SKILL.md`、`references/`）不用改；本风格独有的规则只写在这里。

## 1. 气质三句话

用三句话说清这个风格是什么场景、什么材料、什么情绪。例：「一张铺在桌上的手帐页……」。

## 2. 参考来源

- 用户给的参考图 / 品牌 / 场景，以及每张取它的什么（材质、配色关系、构图），注明「只取感觉」还是「照着做」。

## 3. 基础 token

| 项 | 值 |
|---|---|
| 页面底 | |
| 文字 / 次要文字 | （不用纯黑） |
| 字体 | 正文一种；展示用字体最多一种 |
| 圆角 | 区块 / 卡片 / 按钮 |
| 阴影 | 只表示层级 |
| 区块墨色 | 每块一个，跟它的底走 |
| 强调色 | 只给要注意的 |

## 4. 元素目录

| 元素 | 定版 | 做法（照片 / SVG / CSS） | 被否过的 |
|---|---|---|---|

每改一轮就更新这张表：定版写现在的样子，被否的写用户否掉的方向和原话关键词。

## 5. 隐藏交互

列出彩蛋、触发方式、状态怎么存。

## 6. 不要

用户在反馈里说过的原则和禁忌。
