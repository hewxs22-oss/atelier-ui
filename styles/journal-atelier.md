# 风格包：journal-atelier（手帐 / 拼贴 / 手作工坊）

一张铺在桌上的手帐页：撕边纸片拼贴、和纸胶带、珍珠纽扣、麻绳、火漆封印；工坊里摆着古董剪刀和一方缎布。安静、温暖、有手作的不规则，物件有真实质感。

首个实例：审稿页主页（`tools/review_gloss.html` 的 `#home-page`，规则全文在 `docs/review-home-style-prompt.md`）。

## 1. 气质三句话

- 纸是底，物件是点缀，内容卡片是主角。
- 一切都像手做的：每个实例略不同，没有完全对称。
- 物件要真：木、蜡、麻、金属、缎都用照片素材。

## 2. 基础 token

| 项 | 值 |
|---|---|
| 页面底 | 暖白 `#fcfbf9` + 淡点阵手帐纸（20px 点距，`#e9e3da` 1.1px 圆点） |
| 文字 | 暖深褐 `#3d332b`（不用纯黑），次要 `#8a7d70` |
| 字体 | 正文中英文统一 SF Pro Rounded / 苹方；大数字和空栏提示用手写体（Chalkboard SE）；日期用 Bodoni 72。不用楷书 |
| 大数字 | 约 68px、圆润手写、每块略歪、蜡笔质感滤镜 |
| 圆角 | 区块 24px，卡片 16px，按钮和标签全圆 |
| 阴影 | 只表示「在上一层」：`0 1px 2px rgba(60,40,20,.07), 0 8px 22px rgba(60,40,20,.07)` |
| 区块墨色 | 每块一个，跟它的纸走：珊瑚橙 `#d0864f`、绿 `#4f9e70`、粉 `#d47f93`、紫 `#7880c6` |
| 强调色 | 品牌橙一族，只给要注意的；红色只给真出问题 |

## 3. 元素目录（做法 + 定版 + 被否的路）

| 元素 | 定版 | 做法 | 被否过的 |
|---|---|---|---|
| 区块容器 | 撕边纸片，上下撕边，每张颜色和纸纹不同、略歪 ±0.6°（内容不歪） | CSS 遮罩撕边 + SVG 噪声纸纹 | 统一灰底；马卡龙色块；四张同样纸纹 |
| 纸纹 | 花香纸（偏黄旧，雏菊花瓣叶片）、Westwood 格纹、笔记本内页、错位多色波点 | SVG `feTurbulence` + 稀疏手画元素，淡、不发灰 | 牛皮纸（「丑」）、揉皱纸（「无聊」）、丝帛（选过又改回） |
| 区块标题 | 半透明和纸胶带上直接写字，胶带从纸边伸出、两端撕边；字是区块墨色压深 | CSS + 正片叠底 + 纤维纹理 | 荧光笔；胶带和标题分开各过各的 |
| 说明问号 | 巴洛克珍珠纽扣钉在胶带左端，每颗形状和高光不同 | CSS 多层径向渐变 | 硬白点塑料光；规整圆珠 |
| 内容卡片 | 纯白，统一高度（一栏正好 5 张），内容居中；悬停一圈同墨色的圆头短胶囊虚线 | SVG rect 圆头描边（CSS dotted 在 Chrome 是方点） | 发光边框；卡片角上放剪刀（十几版后全撤） |
| 日期 | 照片级火漆封在纸上沿只露下半块，日期压印在里面；漆绿邮戳波浪线带月.年 | 照片抠图 + SVG 文字 | 挂历、周历纸条、纯邮戳、焦糖色火漆 |
| 退出键 | 浅蜂蜜橡木摆钟照片，指针用 SVG 走真实时间，摆锤刻退出图标 | 照片 + SVG | 怀表、瓷花钟、自己画的钟（「没有真实质感」） |
| 引导线 | 照片级亚麻绳，Verlet 可拖，珍珠钉住，从内容下面穿过 | canvas 贴照片纹理 + 擦除 | 均匀的线；太浅的颜色 |
| 导航分界 | 整条导航栏高度的象牙薄纱：竖向 S 形褶皱，下沿像浪花边缘，零星雏菊和不同方向的小薰衣草；悬停时摆一下 | SVG（要精确透明度） | 笔直分割线（「没有呼吸感」）；横向海浪层 |
| 花 | 实物感薰衣草一束，梗淡绿，从画面外斜伸进来压在火漆下 | 绿幕照片 + 局部重上色 | 钩织风格；梗在火漆左边露出 |
| 古董剪刀 | 底排 20 把只露把手（盲盒）；单击抽出飞到缎布上 | 照片抠图 + Web Animations | SVG 平涂、SVG 金属渐变、水粉方形贴纸 |
| 缎布 | 方形轮廓内揉皱的贝母光泽淡贝壳粉真丝缎，右上抓褶处缝格纹纽扣花（关闭钮） | 绿幕照片 | 满铺蕾丝桌布、雾粉棉缎（太浓）、象牙缎调粉（廉价） |
| 品牌标志 | 柔边不规则海星；收起模式出现同画法扇贝 | SVG + 扰动滤镜 | 规整五角星 |

## 4. 隐藏交互（不加提示）

- 单击火漆：转一圈，切换「雨天」（纸吸潮变深、阴影加重、几块湿痕可拖可晾干）。
- 双击火漆：简约模式（所有装饰「伪装」起来，只剩框架和卡片）。
- 拖麻绳；四颗珍珠都扯开后绳子缩回去绕在火漆上；双击第一颗珍珠复位。
- 单击底排一把剪刀：抽出、飞到缎布上；双击中间偏左那把：全部收成扇贝，火漆隐去。
- 悬停导航栏：薄纱摆一下。
- 状态都存 localStorage，第一帧套上。

## 5. 不要

- 不要让装饰碰内容卡片里的字。
- 不要纯黑大色块、黑底提示框（用奶油色小便签）。
- 不要蓝调色罩表现「氛围」；用纸色加深、阴影、漫反射的光感。
- 不要红色，除非真出问题。
- 不要外链字体和图标库。
- 不要为装饰改格局、加信息或按钮。
